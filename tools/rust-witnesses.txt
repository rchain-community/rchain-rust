# The Rust half of the law register — the tests that witness a proved row's statement.
#
# Each line is `path.rs:symbol`, the shape the register's coming `rustWitness` field will carry, and
# `tools/check-rust-witnesses.sh` runs every one of them by name (refusing a name that matches no
# test — `cargo test` exits 0 on an empty filter, so a registry of renamed or ignored tests would
# otherwise run green while checking nothing).
#
# **This file is transitional and says so.** The register (`spec/Rchain/Laws.lean` → `spec/laws.tsv`)
# is the oracle for what a law's proof is worth, and a list of Rust tests kept anywhere else is a
# second copy of that judgement. It lives here only because `rustWitness` does not exist yet: the
# tree was red when this was written (the sort unit's `Sort.lean` does not elaborate, so the register
# cannot be emitted), and the 56 witnesses below were prose (`falsifiable`/`note` names nothing read)
# until this list made them executable. When the field lands, this file is deleted and the gate pipes
# the column instead.
#
# **What is not here, and why** — six of the 60 law-named tests a name-scan proposes, each classified
# by reading its body (the plan's "Unit 1's population, measured", `~/.claude/plans/spicy-honking-pony.md`):
#
#   * `models/src/property_tests.rs:law4_the_same_program_reduces_to_the_same_state` — determinism,
#     not COMM: a reducer that deterministically produced `Nil` would pass it.
#   * `sdk/src/property_tests.rs:law14_super_majority_is_monotone_in_support` — any monotone
#     threshold passes, so it cannot falsify `3·stake > 2·total`.
#   * `models/src/casper/protocol/casper_message.rs:to_proto_keeps_bonds_and_rejections_in_sorted_order`
#     — named `law16_` until 2026-09-24; its two fields arrive from a `BTreeMap`/`BTreeSet`, already
#     sorted, so with both sorts deleted it passes *and so do all 156 tests in the crate*.
#   * `block-storage/src/dag/message_state.rs:law15_insert_msg_is_monotone` — pins `insert_msg`'s
#     per-sender latest replacement, which law 15's statement does not name.
#   * `block-storage/src/property_tests.rs:law18_a_validation_failed_tip_is_not_indexed` — the
#     `validation_failed` exclusion is a store rule, not one of law 18's two invariants.
#   * `models/src/block_metadata.rs:law18_block_metadata_round_trips` — a codec round trip.
#
# Four more are registered under the row they *assert* rather than the one their name claims: the
# three `law27_*` tests in `casper/src/property_tests.rs` pin the coordinator record (law 29), and
# `models/src/property_tests.rs:law2_sorting_a_sequence_depends_only_on_its_elements` is law 1a's
# content. Their names are left alone — two of them are cited in `spec/TEST-COVERAGE.md`, so renaming
# is a two-file change — and the register's rows say which is which.
