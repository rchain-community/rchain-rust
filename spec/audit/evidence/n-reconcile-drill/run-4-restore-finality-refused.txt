== 6. the fiat, printed before it is applied ==
  This is NOT a sync. The joiners adopt V2's chain state wholesale, so what they agree about
  afterwards is V2's view of the chain — including any block above the point that V2
  accepted and its peers did not. Section 4 enumerates the blocks this drops, one record per unique
  block, with each block's accepted deploy count and the signatures of the deploys its merge
  rejected; that record — not its total, which counts accepted deploys — is what the owners
  re-submit from. Running this is the operator asserting that V2 is the chain. It is a
  stopgap because it depends on the data-dir layout being movable — which #287's design
  deliberately avoided depending on — and not a substitute for an agreed anchor.
