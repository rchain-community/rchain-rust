== what that localises ==

The master answers every request with the *same* page, so the joiner is not being starved and the responder
is not dropping: either the requester asks for the same page each time (its cursor is not advancing) or the
responder ignores the cursor and always answers from the start. Either way the walk neither advances nor
fails — it cannot finish, and the node never leaves NodeSyncing. The next capture is the request itself
(the path the joiner names in each StoreItemsRequest); the code that computes it is
`LfsTupleSpaceRequester`'s request loop, and the responder's path handling is in `node_running.rs`.

== why this did not show on the quiet rigs ==

Every sighting of this shape (three before this one) was against a master that was *producing*; the rigs
that always worked put the joiners against a chain nobody was producing to (solo master, then joiners, then
autopropose off). That is consistent with a cursor that only fails to advance under load — and it is not yet
shown, which is why this is written as the next question rather than as the cause.
